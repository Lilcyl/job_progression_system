
Story
US1 (FR1) As an authorised adviser, I want to log in so that I can access learner application data securely.

Acceptance criteria
- Valid credentials take me to the applications list
- Invalid credentials show an error and no access
- A logout link ends my session

US2 (FR3) As an adviser, I want to see all job applications in a list so that I can review activity quickly.

Acceptance criteria
- List shows learner, employer, vacancy, date, status
- Newest first
- Message shown if there are no records

US3 (FR5) As an authorised adviser, I want to add a job application so that I can track a learner's employment activity.

Acceptance criteria
- Form has learner, vacancy, date applied, status, notes
- Blank learner or no vacancy is rejected with a message
- Valid form saves and shows a success message

US4 (FR6) As an adviser, I want to edit an application so that I can update its status.

Acceptance criteria
- Edit form is pre-filled
- Changes save and appear in the list

US5 (FR7) As an administrator, I want to delete an application so that mistakes are removed.

Acceptance criteria
- A confirmation page appears first
- Cancel keeps the record
- Staff without permission cannot delete

US6 (FR8) As an adviser, I want to search and filter so that I can find an application fast.

Acceptance criteria
- Search matches learner, vacancy or employer
- Status filter narrows results
- No-match shows a clear message


US7 As a learner, I want to be able to apply for a vacancy so that my application process can be tracked by the employer
- Vacancy available to learner to apply for a job
